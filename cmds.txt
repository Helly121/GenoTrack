-------------------------------------------------------------------------------
1. CORE SERVICES (URLS & START COMMANDS)
-------------------------------------------------------------------------------

* Scientific Dashboard:
  URL:     http://localhost:8008/  (or http://127.0.0.1:5500/index.html via Live Server)
  Command: python -m uvicorn src.serve.app:app --host 0.0.0.0 --port 8008 --reload

* FastAPI Interactive Swagger Docs:
  URL:     http://localhost:8008/docs
  Command: (Runs with FastAPI on port 8008)

* Prometheus Telemetry Metrics:
  URL:     http://localhost:8008/metrics
  Command: (Runs with FastAPI on port 8008)

* Prometheus Monitoring UI:
  URL:     http://localhost:9090
  Targets: http://localhost:9090/targets
  Alerts:  http://localhost:9090/alerts
  Command: docker compose up -d prometheus grafana

* Grafana Operational Dashboard:
  URL:     http://localhost:3001  (User: admin | Pass: admin)
  Command: docker compose up -d prometheus grafana
  Stream:  python monitoring/traffic_generator.py --url http://localhost:8008 --interval 2.5

* MLflow Experiment Tracking & Model Registry:
  URL:     http://localhost:5000
  Command: python -m mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000

* Metaflow Visual Cards Server:
  URL:     http://localhost:8324
  Command: python -m pipelines.flow card server --port 8324
  Direct:  python -m pipelines.flow card view validation_gate


-------------------------------------------------------------------------------
2. PIPELINE & OPERATIONAL CLI COMMANDS
-------------------------------------------------------------------------------

# --- Metaflow Pipeline DAG ---
python pipelines/flow.py run
python -m pipelines.flow card view validation_gate
python -m pipelines.flow card server --port 8324

# --- DVC Data Lineage ---
dvc dag
dvc status
dvc repro

# --- MLflow Tracking & Seeding ---
python src/models/seed_mlflow.py
python -m mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000

# --- REST Inference & SHAP Attribution ---
curl -X POST http://localhost:8008/predict/sample -H "Content-Type: application/json" -d "{\"sample_id\": \"A1256\", \"environment\": \"2011_DS\"}"
curl -X GET http://localhost:8008/explain/locus/S1_11984
curl -X GET http://localhost:8008/metrics

# --- Telemetry Generation (Populates Grafana) ---
python monitoring/traffic_generator.py --url http://localhost:8008 --interval 2.5
python monitoring/seed_telemetry.py --endpoint http://localhost:8008 --requests 50

# --- 16-Season Virtual Breeding Simulation ---
python -m simulation.run_lifecycle --scenario storyline_demo --ticks 16
python -m simulation.verify_lifecycle_acceptance

# --- Full Docker Stack ---
docker compose up -d
docker compose ps
docker compose down

# --- Test Suite (29/29 Tests) ---
pytest tests/ -v
