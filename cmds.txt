2. PRESENTATION WALKTHROUGH (STEP-BY-STEP NARRATIVE)
-------------------------------------------------------------------------------

Use this narrative flow during a demonstration:


PART 1: PIPELINE ORCHESTRATION & VISUAL CARDS (METAFLOW)
-------------------------------------------------------------------------------
* Talking Points:
  - Standard ML scripts are hard to track and debug. GenoTrack uses Metaflow
    to orchestrate an 8-step reproducible Directed Acyclic Graph (DAG):
    start -> setup_data -> ingest -> clean -> features -> train -> validation_gate -> register -> end
  - Cross-platform compatibility layer (pipelines/compat.py) transparently
    handles Win32 pipe polling and atomic file replacements.
  - Every step features an interactive visual report (@card decorator)
    rendering data dimensions, QC distributions, and metrics.

* Demonstration Commands:
  1. Run the complete end-to-end DAG (ingest -> QC -> features -> train -> gate -> register):
     python pipelines/flow.py run

  2. List all generated step cards:
     python pipelines/flow.py card list

  3. View the automated Validation Gate report card in your default browser:
     python -m pipelines.flow card view validation_gate

  4. Or launch the interactive Metaflow Card Server on port 8324:
     python -m pipelines.flow card server --port 8324


PART 2: EXPERIMENT TRACKING & MODEL GOVERNANCE (MLFLOW)
-------------------------------------------------------------------------------
* Talking Points:
  - Production genomic selection demands rigorous lineage tracking. GenoTrack
    uses MLflow backed by SQLite (sqlite:///mlflow.db).
  - Tracks hyperparameter configurations, dataset hashes, and cross-validation
    performance.
  - Pre-seeded with 4 comparative historical runs demonstrating model evolution:
    1. GBLUP Baseline (Linear Additive Ridge): r = 0.5420, RMSE = 812.4 kg/ha
    2. Naive Split Leakage (Unstratified Random): r = 0.8910 (flagged for genetic leakage)
    3. Challenger v1 LightGBM (Population Stratified): r = 0.7845, RMSE = 789.2 kg/ha
    4. Champion v2 XGBoost (Kinship Stratified GxE): r = 0.8122, RMSE = 768.8 kg/ha
  - Demonstrates the formal Model Registry lifecycle:
    Version 1 (Archived), Version 2 (Production), Version 3 (Staging).

* Demonstration Commands:
  # Launch the MLflow UI (if not already running):
  python -m mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000

  # (Optional) Re-seed comparative runs and registry versions:
  python src/models/seed_mlflow.py

* What to Show in Browser (http://localhost:5000):
  1. Open the "genotrack_rice_grain_yield" experiment.
  2. Select all runs and click "Compare" to show the scatter/parallel-coordinates
     chart of Pearson r vs RMSE.
  3. Click "Models" -> "GenoTrack-GxE-Yield" to show stage transitions
     (Production vs Staging).


PART 3: REAL-TIME SERVING & BIOLOGICAL EXPLAINABILITY (FASTAPI + SHAP)
-------------------------------------------------------------------------------
* Talking Points:
  - Trained models are served via high-performance async FastAPI with
    lifespan memory caching.
  - Decomposes trait predictions into additive genetic potential vs.
    environmental trial effects.
  - Implements per-locus SHAP (SHapley Additive exPlanations) attribution,
    mapping genomic importance scores directly to physical chromosome IDs and
    base-pair positions.
  - Powers the live WebGL 3D Genomic Locus Inspector in index.html.

* Demonstration Commands:
  # Launch the FastAPI serving application on port 8008:
  python -m uvicorn src.serve.app:app --host 0.0.0.0 --port 8008 --reload

  # Test sample prediction with SHAP marker attribution:
  curl -X POST http://localhost:8008/predict/sample ^
    -H "Content-Type: application/json" ^
    -d "{\"sample_id\": \"A1256\", \"environment\": \"2011_DS\"}"

  # Query specific SNP marker locus attribution:
  curl -X GET http://localhost:8008/explain/locus/S1_11984

* What to Show in Browser:
  1. Open http://localhost:8008/ to show the precision scientific dashboard
     and live 3D Locus Inspector.
  2. Open http://localhost:8008/docs to show the interactive Swagger UI.


PART 4: PRODUCTION MONITORING & SLA OBSERVABILITY (PROMETHEUS + GRAFANA)
-------------------------------------------------------------------------------
* Talking Points:
  - Deployed models drift over seasons due to climate variability and field
    measurement error.
  - GenoTrack exports real-time metrics via Prometheus (/metrics):
    * genotrack_predictions_total: Throughput by trial environment and status.
    * genotrack_inference_latency_seconds: Latency histogram tracking p50, p95, and p99 SLAs.
    * genotrack_predicted_yield_kg_ha: Distribution histogram of predicted crop yields.
    * genotrack_covariate_missing_hill_ratio: Covariate tracking for detecting field drift.
    * genotrack_active_model_version: Gauge reporting the production model version.
  - Grafana is pre-provisioned via code with custom panels and alert thresholds.

* Demonstration Commands:
  # 1. Start Prometheus and Grafana containers:
  docker compose up -d prometheus grafana

  # 2. Start continuous live traffic stream (keeps Grafana actively updating):
  python monitoring/traffic_generator.py --url http://localhost:8008 --interval 2.5
  # (Or send a single 50-request burst):
  # python monitoring/seed_telemetry.py --endpoint http://localhost:8008 --requests 50

  # 3. Check live scraped metrics:
  curl http://localhost:8008/metrics

* What to Show in Browser:
  1. Prometheus Targets (http://localhost:9090/targets):
     - Show genotrack-api reporting 1/1 UP (100% green health).
     - Confirms Prometheus is actively scraping FastAPI /metrics endpoint every 5s.

  2. Prometheus Alerting Rules (http://localhost:9090/alerts):
     - Demonstrates enterprise MLOps alerting with 4 active rules:
       * HighInferenceLatency (p95 > 300ms SLA warning)
       * SevereCovariateDrift (missing hill ratio > 20% data drift warning)
       * GenoTrackAPIOffline (instance down critical alert)
       * ElevatedPredictionErrors (5xx error rate critical alert)
     - Explain how rule states transition from Inactive -> Pending -> Firing.

  3. Prometheus PromQL Live Graph:
     - URL: http://localhost:9090/graph?g0.expr=sum(rate(genotrack_predictions_total[1m]))%20by%20(environment)&g0.tab=0&g0.range_input=15m
     - Renders real-time multi-line throughput curves broken down across all 7 trial environments.
     - Note: Default http://localhost:9090 opens with an empty query box ("No data queried yet");
       always open the pre-executed URL above or click Execute to render graphs instantly.

  4. Grafana Dashboard (http://localhost:3001):
     - Log in with admin / admin.
     - Open Dashboards -> MLOps -> GenoTrack MLOps Telemetry & Model Monitoring.
     - Show the panels updating in real time: Prediction Throughput, Latency Percentiles
       (p50/p95), Yield Distribution, and Missing Hill Covariate Drift.


PART 5: FULL-STACK CONTAINERIZATION (DOCKER COMPOSE)
-------------------------------------------------------------------------------
* Talking Points:
  - The entire environment is containerized and deployable in a single command.
  - Connects API (8008), Prometheus (9090), Grafana (3001), and MLflow (5000)
    inside an isolated bridge network "genotrack-net".

* Demonstration Commands:
  # Spin up full stack:
  docker compose up -d

  # Check container status:
  docker compose ps

  # View container logs:
  docker compose logs -f prometheus grafana

  # Tear down stack:
  docker compose down


PART 6: GOVERNANCE & CI/CD (GITHUB ACTIONS)
-------------------------------------------------------------------------------
* Talking Points:
  - GenoTrack enforces enterprise safety gates across 4 specialized GitHub
    Actions workflows in .github/workflows/:
    1. Code CI (ci_code.yml): Flake8 linting, Black formatting checks, and 16 unit tests.
    2. Data CI (ci_data.yml): Pandera contract validation on mutated/corrupted fixtures.
    3. Continuous Training (continuous_training.yml): Automated retrain and gate evaluation.
    4. Deployment & Lightweight RBAC (deploy.yml): Multi-stage deployment
       (staging -> production). Uses GitHub Actions Environment Protection Rules
       requiring designated human reviewer approval (lead agronomist / ML lead)
       before promoting a model to production.

* Demonstration Commands:
  # Run the full test suite locally (16/16 tests passing):
  pytest

3. ONE-CLICK PRESENTATION LAUNCHER
-------------------------------------------------------------------------------

You can launch all presentation servers simultaneously using the bundled
Windows launcher:

  .\demo_commands.bat

Or execute the commands individually in separate terminal tabs:

  # Terminal 1: FastAPI Serving Server
  python -m uvicorn src.serve.app:app --host 0.0.0.0 --port 8008

  # Terminal 2: MLflow UI
  python -m mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000

  # Terminal 3: Docker Telemetry Stack (Prometheus + Grafana)
  docker compose up -d prometheus grafana

  # Terminal 4: Telemetry Replay Generator
  python monitoring/seed_telemetry.py --endpoint http://localhost:8008 --requests 50

  # Terminal 5: Metaflow Card Viewer
  python -m pipelines.flow card view validation_gate
